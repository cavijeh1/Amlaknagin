# املاک نگین پرو — نسخه آنلاین چنددستگاهی

این نسخه به‌جای LocalStorage از یک سرور Node.js و فایل دیتابیس JSON استفاده می‌کند و برای شروع کار نیازی به MySQL ندارد.

## امکانات
- ثبت آگهی از هر گوشی
- آپلود تا ۶ عکس برای هر آگهی
- ذخیره عکس‌ها روی سرور
- آگهی جدید ابتدا «در انتظار تأیید» است
- فقط آگهی‌های تأییدشده برای کاربران عمومی نمایش داده می‌شوند
- ورود مدیر، تأیید، رد، ویرایش، حذف و فروش‌رفته
- آگهی ویژه از پنل مدیر
- علاقه‌مندی‌ها روی هر گوشی مستقل است
- بکاپ و بازیابی از پنل

## اجرا روی کامپیوتر یا VPS
Node.js 18+ نصب باشد:

```bash
npm start
```

سپس:
`http://IP-SERVER:3000`

## تغییر رمز مدیر
متغیرهای محیطی زیر را قبل از اجرا تنظیم کنید:

`ADMIN_USERNAME`
`ADMIN_PASSWORD`

## نکته مهم برای اینترنت عمومی
برای استفاده واقعی، دامنه + HTTPS + رمز مدیر قوی توصیه می‌شود. دیتابیس فعلی فایل JSON است و برای شروع سبک مناسب است؛ اگر تعداد آگهی و کاربران زیاد شد، می‌توان آن را به MySQL/PostgreSQL منتقل کرد.
